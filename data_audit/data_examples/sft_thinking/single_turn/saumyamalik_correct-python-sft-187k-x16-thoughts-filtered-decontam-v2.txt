To solve this problem, we need to remove all space characters (ASCII 32) from a given string and output the resulting string. The solution should handle any printable ASCII characters and ensure that leading and trailing spaces are also removed.

### Approach
The approach involves reading the input string, removing all space characters, and then printing the modified string. The key steps are:

1. **Read the Input:** Read the entire line of input as a string, which includes any leading or trailing spaces.
2. **Remove Spaces:** Use the `replace` method to replace all space characters with an empty string, effectively removing them.
3. **Output the Result:** Print the modified string, ensuring it ends with a newline character as required.

This approach efficiently handles all occurrences of space characters regardless of their position in the string and ensures the output adheres to the specified format.

### Solution Code
```python
print(input().replace(' ', ''))
```

### Explanation
- **Reading Input:** The `input()` function reads a line from input, which includes all characters up to but not including the newline character.
- **Removing Spaces:** The `replace(' ', '')` method call on the input string replaces every space character (ASCII 32) with an empty string, thus removing all spaces.
- **Printing the Result:** The `print` function outputs the modified string followed by a newline character, ensuring the output meets the problem's requirements.

This solution efficiently processes the input in linear time relative to the length of the input string, making it both time and space efficient.

### Approach
The approach involves using a dictionary to map each valid status value to its corresponding message. By checking the input status against this mapping, we can efficiently determine the appropriate response. If the input status is not found in the mapping, we default to the 'Invalid status' message. This method is both concise and easy to maintain, especially if additional status values need to be supported in the future.

### Solution Code

```python
def server_status(req: dict) -> dict:
    status_mapping = {
        'online': 'Server is running smoothly',
        'offline': 'Server is down',
        'maintenance': 'Server is under maintenance'
    }
    input_status = req.get('status', None)
    if input_status in status_mapping:
        return {'status': status_mapping[input_status]}
    else:
        return {'status': 'Invalid status'}
```

2. **Retrieve Input Status**: The input dictionary `req` is accessed to get the 'status' value. Using `.get('status', None)` ensures that if the key is missing, it returns `None` (though the problem states the input will have the key, this adds a layer of safety).
3. **Check and Return Result**: The input status is checked against the keys in `status_mapping`. If it exists, the corresponding message is returned. If not, 'Invalid status' is returned.

This approach efficiently handles all specified cases with minimal code, ensuring clarity and maintainability.
