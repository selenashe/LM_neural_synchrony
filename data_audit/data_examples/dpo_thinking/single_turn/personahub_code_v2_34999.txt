To calculate the average duration of yoga sessions from a list of session durations in minutes, we can follow a straightforward approach:

---

### ✅ Problem Breakdown

- **Input**: A list of integers where each integer represents the duration of a yoga session in minutes.
- **Output**: A float representing the average duration, **rounded to two decimal places**.
- **Constraints**: The input list is guaranteed to have **at least one element**.

---

### 🧠 Key Steps

1. **Sum the durations** in the list.
2. **Divide the total** by the number of sessions to get the average.
3. **Round the result** to two decimal places using Python's `round()` function.

---

### 🛠️ Python Function Implementation

```python
def average_yoga_duration(session_durations):
    """
    Calculate the average duration of yoga sessions rounded to two decimal places.

    Parameters:
    session_durations (list of int): List of yoga session durations in minutes.

    Returns:
    float: Average duration rounded to two decimal places.
    """
    total = sum(session_durations)
    average = total / len(session_durations)
    return round(average, 2)
```

---

### 📌 Example Usage

```python
# Example input
session_durations = [60, 45, 30, 90, 120]

# Compute average
average_duration = average_yoga_duration(session_durations)

# Output
print(average_duration)  # Output: 69.0
```

> **Note**: Although the example shows `69.00`, Python represents the float `69.0` as `69.0`, and when printed with formatting (e.g., `"{:.2f}".format(69.0)`) it would display as `69.00`.

---

### 📎 Additional Notes

- **Rounding Behavior**: Python uses "bankers rounding" (rounds to the nearest even number when the number is exactly halfway between two values), which is standard in most programming languages.
- **Float Precision**: Floats in Python (and most languages) can sometimes have precision issues due to binary representation. If strict formatting is required (e.g., always showing two decimal places), consider returning the result as a string using formatting like `"{:.2f}".format(value)`.

Here is a well-documented Python function that converts a list of integers into a dictionary where each key is an integer from the list, and its corresponding value is the square of that integer.

---

### ✅ Function Definition

```python
def list_to_square_dict(input_list):
    """
    Converts a list of integers into a dictionary where each integer is a key,
    and the corresponding value is the square of that integer.

    Parameters:
        input_list (list of int): A list of integers.

    Returns:
        dict: A dictionary with integers as keys and their squares as values.
    """
    return {num: num**2 for num in input_list}
```

---

### 🧪 Example Usage

```python
# Example 1: Standard input
print(list_to_square_dict([1, 2, 3, 4]))
# Output: {1: 1, 2: 4, 3: 9, 4: 16}

# Example 2: Empty list
print(list_to_square_dict([]))
# Output: {}

# Example 3: List with negative numbers
print(list_to_square_dict([-2, -1, 0, 1, 2]))
# Output: {-2: 4, -1: 1, 0: 0, 1: 1, 2: 4}

# Example 4: List with duplicate elements
print(list_to_square_dict([2, 2, 3, 3]))
# Output: {2: 4, 3: 9}
```

---

### 🔍 Explanation

- The function uses a **dictionary comprehension**, which is a concise and readable way to construct a dictionary in Python.
- The expression `{num: num**2 for num in input_list}` iterates over each number in the input list and maps it to its square.
- If the input list is empty, the dictionary comprehension naturally returns an empty dictionary, which meets the requirement.
- Duplicate elements in the list will result in only one key-value pair for each unique number since dictionary keys must be unique.

```python
def convert_to_dict(numbers):
```

To solve the problem of determining whether a given text contains any of the words from a list of keywords (case-insensitively), we can implement a Python function that performs a **substring-based search**. The logic is designed to be both **case-insensitive** and **efficient**, avoiding repeated string conversions by performing a single transformation on the input text.

---

### ✅ Key Requirements:
- **Input**: 
  - A string `text`
  - A list of strings `keywords`
- **Output**: 
  - `True` if **any** of the keywords (case-insensitively) is a **substring** of the text.
  - `False` otherwise.
- **Case-insensitive comparison** is required.
- **Substring match** is sufficient (i.e., it's not necessary for the keyword to be a standalone word).

---

### ✅ Implementation Strategy:
1. Convert the entire `text` to lowercase once.
2. Iterate through each keyword in the `keywords` list.
3. For each keyword, convert it to lowercase and check if it is a substring of the lowercase `text`.
4. If a match is found, return `True`.
5. If no match is found after all keywords are checked, return `False`.

This approach ensures:
- Only one lowercase conversion of the input text.
- Efficient keyword checks using Python's `in` operator for substring matching.
- Case-insensitive comparison.

---

### ✅ Python Function:

```python
def contains_keyword(text, keywords):
    """
    Check if any of the keywords (case-insensitive) is a substring of the given text.

    Parameters:
    text (str): The input text to search within.
    keywords (list of str): List of keywords to search for.

    Returns:
    bool: True if any keyword is found as a substring (case-insensitive), else False.
    """
    lower_text = text.lower()
    for keyword in keywords:
        if keyword.lower() in lower_text:
            return True
    return False
```

---

### ✅ Example Usage:

```python
text = "The political landscape in Algeria is evolving rapidly."
keywords = ["evolving", "revolution", "policy"]

print(contains_keyword(text, keywords))  # Output: True
```

- The keyword `"evolving"` is found as a substring in the text.
- The function returns `True` immediately upon finding a match.

Here's a well-documented Python function that automates the categorization of expenses based on keyword matching in the expense descriptions. It adheres to the problem's requirements, including:

```python
def categorize_expenses(expenses, categories):
    """
    Categorizes a list of expenses based on provided keywords for each category.

    Parameters:
        expenses (list of dict): A list of expense dictionaries, each containing:
            - "amount": float
            - "date": str (format "YYYY-MM-DD")
            - "description": str

        categories (dict): A dictionary mapping category names to lists of keywords.

    Returns:
        list of dict: A list of dictionaries with an added "category" key.
    """
    categorized_expenses = []

    for expense in expenses:
        # Create a copy of the expense to avoid modifying the original
        new_expense = expense.copy()
        new_expense["category"] = "Uncategorized"
        description = new_expense["description"]

        # Iterate through each category in the order they were inserted
        for category, keywords in categories.items():
            # Check if any keyword is a substring of the description
            if any(keyword in description for keyword in keywords):
                new_expense["category"] = category
                break  # Stop checking once a match is found

        categorized_expenses.append(new_expense)

    return categorized_expenses
```
