### Part 1: Proving the Uniqueness of the Minimum Spanning Tree

We are given a **connected weighted undirected graph $ G $** with $ n $ nodes and $ m $ edges. The task is to prove that:

- The **minimum spanning tree (MST)** is **unique** **if and only if all edge weights are distinct**.

---

#### Key Reasoning:

1. **MST Uniqueness Condition**:
   - A graph has a unique MST if and only if there are **no multiple edges or parallel edges** with the same weight.
   - If all edge weights are distinct, the MST is uniquely determined, as there is **exactly one way** to select a set of edges that connect all nodes with the **minimum total weight**.

2. **Contrapositive**:
   - If there are **multiple edges with the same weight**, then there are **multiple MSTs**, since different sets of edges can still yield the same total weight.

Thus, the condition **"all edge weights are distinct"** is **necessary and sufficient** for the uniqueness of the MST.
