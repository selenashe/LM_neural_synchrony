To solve this problem, we need to read a student's name and their course grades from standard input and output a properly formatted JSON object representing the student's information. The JSON object should include the student's name and a dictionary of their grades by course.

---

### ✅ **Approach Overview**

1. **Read the Student's Name**:  
   The first line of input is the student's name. We read it directly using `input().strip()` to remove any leading or trailing whitespace.

2. **Read the Number of Courses**:  
   The second line is an integer `n`, which tells us how many course grades follow.

3. **Read and Parse Course Data**:  
   For each of the next `n` lines, we read a line that contains a course name and its corresponding grade. To handle course names that may contain spaces, we split the line into parts using `split()`, and then:
   - Reconstruct the course name using all parts except the last one.
   - Convert the last part to an integer as the grade.

4. **Construct the JSON Object**:  
   We build a dictionary with the keys `"student_name"` and `"grades"`:
   - `"student_name"` holds the student's name as a string.
   - `"grades"` is a dictionary mapping course names to their respective grades.

5. **Output as JSON**:  
   We use Python’s `json.dumps()` function with an indentation of 4 spaces to format and print the JSON output.

---

### 🧠 **Implementation Details**

- **Handling Course Names with Spaces**:  
  If a course name like "Art History" appears in the input, we ensure that the entire course name is captured correctly by joining all parts of the input line except the last one.

- **Error Assumptions**:  
  The problem guarantees that the input is correctly formatted. Therefore, we do not need to handle invalid input such as non-integer grades.

- **JSON Formatting**:  
  Python's `json` module ensures that all strings are enclosed in double quotes and the structure is valid JSON, regardless of how the dictionary is written in Python.

---

### 🧪 **Example**

**Input:**
```
John Doe
3
Math 92
Science 85
History 88
```

**Output:**
```json
{
    "student_name": "John Doe",
    "grades": {
        "Math": 92,
        "Science": 85,
        "History": 88
    }
}
```

---

### 🧑‍💻 **Python Code**

```python
import json

# Read student name
student_name = input().strip()

# Read number of courses
n = int(input().strip())

# Initialize dictionary for grades
grades = {}

# Read course and grade information
for _ in range(n):
    line = input().strip()
    parts = line.split()
    course = ' '.join(parts[:-1])
    grade = int(parts[-1])
    grades[course] = grade

# Construct the data dictionary
data = {
    "student_name": student_name,
    "grades": grades
}

# Output the JSON with indentation
print(json.dumps(data, indent=4))
```

To implement an efficient sorting algorithm with **O(n log n) time complexity** using standard input and output, and without using built-in Python functions (such as `sorted` or `sort`), we can utilize the **merge sort algorithm**. This approach is both optimal and easy to implement, as it ensures a clear division into smaller subarrays, followed by a recursive merge.

---

### ✅ Algorithm Overview

- **Merge Sort**:
  - Recursively splits the array into two halves.
  - Sorts each half using the same algorithm.
  - Merges the two sorted halves into a single sorted array.

- **Merge Function**:
  - Combines two sorted lists into a single sorted list in **O(n)** time.

- **Recursive Base Case**:
  - If the array has one or zero elements, it is already sorted.

---

### 🧠 Implementation

Here is the Python code that implements the merge sort algorithm:

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    n = int(data[0])
    arr = list(map(int, data[1:n+1]))
    sorted_arr = merge_sort(arr)
    print(' '.join(map(str, sorted_arr)))

    main()
```
