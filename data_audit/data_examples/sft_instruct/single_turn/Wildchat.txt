They ... each other for a long time.A.knowB.knowsC.are knowingD.have knownE.has known

--- [assistant] ---
The correct answer is **D. have known**.

So the complete sentence is:

**They have known each other for a long time.**

Explanation:
- "They" is plural, so we use "have" (not "has").
- "For a long time" suggests an action that started in the past and continues to the present, which requires the present perfect tense ("have known").
- "Know" is usually a stative verb, so "are knowing" is not correct.

I need to write a vba code that will copy only the cells in column A that have values form sheets "Prem PM", "Prem AA", "Prem CL", Prem SU", and "Prem MG", in that order and paste into sheet "Observe" column E starting from row 2

--- [assistant] ---
Certainly! Below is a VBA macro that will:

- Copy all **non-empty** cells from **Column A** of each sheet (`"Prem PM"`, `"Prem AA"`, `"Prem CL"`, `"Prem SU"`, `"Prem MG"`, **in that order**)
- Paste the values into **Sheet "Observe"**, starting at **cell E2**, one after another (no blanks).

You can paste this code into a module in the VBA editor (ALT+F11 > Insert > Module), then run the macro.

```vba
Sub CopyValuesToObserve()
    Dim wsNames As Variant
    Dim wsDest As Worksheet
    Dim lastRow As Long, destRow As Long, i As Long
    Dim ws As Worksheet
    Dim rng As Range, cell As Range

    wsNames = Array("Prem PM", "Prem AA", "Prem CL", "Prem SU", "Prem MG")
    Set wsDest = ThisWorkbook.Sheets("Observe")
    destRow = 2 ' Start at row 2 in "Observe" Sheet, Column E

    For i = LBound(wsNames) To UBound(wsNames)
        On Error Resume Next
        Set ws = ThisWorkbook.Sheets(wsNames(i))
        On Error GoTo 0
        
        If Not ws Is Nothing Then
            lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
            ' Loop rows from 1 to lastRow
            For Each cell In ws.Range("A1:A" & lastRow)
                If Trim(cell.Value) <> "" Then
                    wsDest.Cells(destRow, "E").Value = cell.Value
                    destRow = destRow + 1
                End If
            Next cell
            Set ws = Nothing
        End If
    Next i
End Sub
```

---

**What this code does:**
- Looks at only the mentioned sheets, in the specific order.
- Takes values **only from cells with data** in column A.
- Pastes them **contiguously** into "Observe", starting at E2.

**How to run:**
1. Open VBA editor (`Alt+F11`).
2. Insert a **Module**.
3. Paste the above code.
4. Press `F5` while cursor is in the code, or create a button and assign the macro.
