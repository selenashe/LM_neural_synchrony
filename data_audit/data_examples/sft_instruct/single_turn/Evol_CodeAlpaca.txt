You can create a SwiftUI application showing a list of products and allowing users to add a product to a list of favorites like shown below.

First, we create a product struct as a data type for our application.

```swift
struct Product: Identifiable {
    let id = UUID()
    var name: String
    var isFavorite: Bool = false
}
```

Then will construct our view showing a list of products and providing a way for users to add specific products to a list of favorites.

```swift
struct ContentView: View {
    @State private var products = [Product(name: "Product 1"), Product(name: "Product 2"), Product(name: "Product 3")]

    var body: some View {
        NavigationView {
            List {
                ForEach(products.indices, id: \.self) { index in
                    HStack{
                        Text(self.products[index].name)
                        Spacer()
                        
                        Button(action: {
                            self.products[index].isFavorite.toggle()
                        }) {
                            Image(systemName: self.products[index].isFavorite ? "star.fill" : "star")
                                .foregroundColor(self.products[index].isFavorite ? .yellow : .gray)
                        }
                        
                    }
                }
            }
            .navigationBarTitle("Product List")
        }
    }
}
```

Here in our `ContentView`, we have a `NavigationView` with a `List` inside, we use `ForEach` to iterate over each product in our `products` array and display its name.

Then we have a `Button` which toggles the `isFavorite` property of the tapped product, changing its state from favorite to not favorite and vice versa.

The button's image will dynamically change from `star` to `star.fill` and vice versa depending on whether or not the product is a favorite.

Please note that to save the state of favorites across launches of your application, you would need to implement a data persistence solution which may include solutions like Core Data, UserDefaults or a server-side database. That would involve more complex code which is not covered in this example.

Take into consideration the provided input sentence, effectively invert the order of the individual words presenting themselves within the sentence, thereby manufacturing an altered version of the sentence where terms feature in a reversed sequence. 
Input: Hello World

--- [assistant] ---
You can solve this problem with Python. Here is a simple program to reverse the words in a sentence.

```python
def reverse_sentence(sentence):
    words = sentence.split(' ')
    reversed_sentence = ' '.join(reversed(words))
    return reversed_sentence

input_sentence = "Hello World"
print(reverse_sentence(input_sentence))
```

When you run this program with "Hello World" as the input, the output will be "World Hello". The split function breaks the sentence into a list of words, and the reversed function changes the order of the elements in this list. Finally, ' '.join creates a string from this reversed list.
