--- [user] ---
Write a Python program that reads a single line of text from the standard input, then extracts and outputs a list of all email addresses found in the string using regular expressions. The program should:

- Extract emails accounting for subdomains, special characters in usernames, and uncommon top-level domains.
- Only include emails where the domain part (the part after '@' and before the top-level domain) contains at least one hyphen '-'.
- Output a Python list (as per print(list)) of all matching email addresses, preserving their original order in the text.

Input Format:
A single line of text containing one or more email addresses.

Output Format:
A Python list (as printed by print([...])) containing all matching email addresses.

Example:
Input:
Contact us at info@sub-example.com and support@test-mail.org or jane.doe-sample@domain-name.info

Output:
['info@sub-example.com', 'support@test-mail.org', 'jane.doe-sample@domain-name.info']

--- [assistant] ---
import re

def main():
    text = input()
    pattern = r'\b[A-Za-z0-9._%+-]+@(?:[A-Za-z0-9-]+\.)*-?[A-Za-z0-9-]*[A-Za-z0-9]-[A-Za-z0-9]*\.[A-Za-z]{2,}\b'
    # First, extract all email-like matches
    potential_emails = re.findall(pattern, text)
    # Now, filter to ensure at least one hyphen in the domain part (after '@' and before last '.')
    filtered_emails = []
    for email in potential_emails:
        if '@' in email:
            domain_part = email.split('@', 1)[1]
            # Remove TLD for precise domain extraction
            idx = domain_part.rfind('.')
            if idx > 0:
                dom = domain_part[:idx]
                if '-' in dom:
                    filtered_emails.append(email)
    print(filtered_emails)

if __name__ == "__main__":
    main()

--- [user] ---
You are tasked with creating a simple messaging function that formats a message sent from one user to another. Implement a function `format_message(sender: str, recipient: str, message: str) -> str` that takes three string arguments: `sender`, `recipient`, and `message`. The function should return a string in the format '<sender>: message'. For example, if the `sender` is 'Alice', the `recipient` is 'Bob', and the `message` is 'Hello, Bob!', the output should be '<Alice>: Hello, Bob!'.

--- [assistant] ---
def format_message(sender: str, recipient: str, message: str) -> str:
    """
    Formats a message from one user to another.

    Parameters:
        sender (str): The name of the person sending the message.
        recipient (str): The name of the person receiving the message (unused in current format).
        message (str): The content of the message.

    Returns:
        str: A string formatted as '<sender>: message'.
    """
    return f"<{sender}>: {message}"

--- [user] ---
Write a program that reads a single line string from standard input, and prints 'True' if the input string is a palindrome, and 'False' otherwise. The program should ignore any non-alphanumeric characters and be case-insensitive when checking for a palindrome.

Input:
A single line containing a string.

Output:
Print 'True' if the processed string is a palindrome, 'False' otherwise.

Example:
Input:
A man, a plan, a canal: Panama

Output:
True

--- [assistant] ---
def main():
    s = input().strip()
    cleaned = [char.lower() for char in s if char.isalnum()]
    cleaned_str = ''.join(cleaned)
    print(str(cleaned_str == cleaned_str[::-1]))

if __name__ == "__main__":
    main()

--- [user] ---
Given a list of numbers as input, write a program that finds and prints the maximum value in the list.

Input:
- The first line contains an integer n, representing the number of elements in the list (n ≥ 0).
- The second line contains n space-separated integers, which are the elements of the list.

Output:
- Print the maximum value in the list.
- If the list is empty (n = 0), print 'None'.

Example:
Input:
5
1 3 2 9 5

Output:
9

--- [assistant] ---
def main():
    n_and_rest = input().split()
    n = int(n_and_rest[0])
    if n == 0:
        print('None')
    else:
        nums = list(map(int, input().split())) if len(n_and_rest) == 1 else list(map(int, n_and_rest[1:]))
        print(max(nums))

if __name__ == "__main__":
    main()

--- [user] ---
Given a JSON object, recursively flatten the object into a single-level dictionary where the keys are dot-separated paths to the original keys. Keys must be sorted in lexicographical order in the output regardless of their original nesting or order. If a value is a list, include the index of the list in the path (e.g., 'a.0.b' for {'a': [{'b': 3}]}). The input will be provided as a valid JSON string via standard input. The output should be a single valid JSON object on one line representing the flattened dictionary, with the keys in lexicographical order.

Input:
A single line containing a valid JSON object.

Output:
A single JSON object (string), where the keys are the dot-separated flattened paths, sorted lexicographically.

Example:
Input:
{"a": 1, "b": {"c": 2, "d": {"e": 3}}}
Output:
{"a": 1, "b.c": 2, "b.d.e": 3}

--- [assistant] ---
import json
import sys

def flatten_json(json_obj, parent_key='', sep='.'):    
    items = {}
    if isinstance(json_obj, dict):
        for k in sorted(json_obj.keys()):
            v = json_obj[k]
            new_key = f"{parent_key}{sep}{k}" if parent_key else k
            items.update(flatten_json(v, new_key, sep=sep))
    elif isinstance(json_obj, list):
        for i, v in enumerate(json_obj):
            new_key = f"{parent_key}{sep}{i}" if parent_key else str(i)
            items.update(flatten_json(v, new_key, sep=sep))
    else:
        items[parent_key] = json_obj
    return items

def main():
    s = sys.stdin.read()
    json_obj = json.loads(s)
    flat = flatten_json(json_obj)
    ordered = dict(sorted(flat.items()))
    print(json.dumps(ordered, separators=(", ", ": ")))

if __name__ == "__main__":
    main()
